Structured content for the terminal.

Lumen is an open protocol for blocks, text runs, layout and events. Rich blocks get proportional type and browser-style layout; grid blocks host legacy terminal apps, so old and new share one document.

Read the specView on GitHub

block.rich

Rich blocks

Proportional fonts, wrapping and layout, described as structured data rather than escape codes.

block.grid

Grid blocks

A cell grid on its own PTY, sized to the block, so existing terminal apps keep working inside a Lumen document.
