Linux cursor rendering proof
Revision: e78176893459a6fa766ba6d9abe130338f3078a5 (the code head; later commits only add proof files)
Host: a throwaway Ubuntu 24.04 x86_64 virtual machine, terminated afterwards; Rust installed fresh as a throwaway user; the window shown by an X virtual framebuffer (1280x800) with a lightweight window manager, so a real window gets and loses focus.
Build: cargo build --release -p lumen-term --features window, inside the machine; binary SHA-256 b2681249867f9c7753de0b2477affb91bf8458aef5ab2aa00b0cb1e09ead9eff
Program in the window: sh -c "printf 'cursor test\r\n'; printf '<sequence>'; sleep 120", window 640x360, captured with import -window. Unfocused: a second window (xterm) was given the focus.
Numbers are from linux-measurements.txt: each capture compared with the hidden baseline.

- linux-block.png: steady block, a full cell (152 pixels differ, 8x19).
- linux-underline.png: two rows at the foot of the cell.
- linux-bar.png: two columns, full height.
- linux-unfocused.png: the same cell, outline only; the cell centre is untouched.
- linux-blink-on.png and linux-blink-off.png: DECSCUSR 1; of eight captures about 0.15 s apart, three were drawn and five were not; the drawn ones are identical to the focused block.
- linux-hidden.png: DECTCEM off, the baseline.
